# Отдельный публичный адрес для начала записи

Гость переходит с главной страницы `/` по ссылке «Записаться» на `/book`. У страницы записи есть собственный адрес, чтобы её можно было открыть напрямую, обновить или вернуться с неё на главную кнопкой браузера «Назад» после перехода.

Обе страницы открываются без регистрации, а переход между ними работает даже при недоступном API. На первом этапе `/book` показывает сообщение «Онлайн-запись пока недоступна» и ссылку «На главную». Это позволяет проверить путь гостя до появления выбора слота и подтверждения брони.
